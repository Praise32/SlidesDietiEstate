Backend: API, Sicurezza e Pattern

Architettura server-side, integrazioni e design patterns implementati

API Router

L'architettura REST è organizzata in router modulari per separare le responsabilità e facilitare la manutenzione:

Login / Auth Admin Agencies Posts Appointments Invites

Integrazioni Esterne

  • Meteo (Open-Meteo)

    Integrazione API per fornire previsioni meteo durante la prenotazione visite.

  • Notifiche (Nodemailer)

    Sistema automatico di invio email per conferme appuntamenti.

  • Storage (AWS S3)

    Upload sicuro e scalabile delle immagini tramite SDK AWS.

Design Patterns & Middleware

Middleware & Security

Implementazione Chain of Responsibility per la pipeline di richiesta: Auth JWT, RBAC (requireRole), validazione Zod e upload file (multer-s3).

Repository Pattern

Separazione netta tra logica di business e accesso ai dati. Incapsula le query Drizzle ORM garantendo un codice più testabile e manutenibile.

Strategy Pattern

Utilizzato tramite Passport.js per gestire strategie di autenticazione intercambiabili: Local (email/password), JWT (token) e Google OAuth.

Factory, DTO & Singleton

Factory (drizzle-zod) per generare schemi; DTO (Zod) per validare input/output; Singleton per l'istanza unica di connessione al DB.
